# Ashwini Gathekar — Portfolio

Personal portfolio built with React and Vite ("Midnight developer" theme).

## Run locally

```bash
npm install
npm run dev
```

## Edit content

All text, projects, skills and links live in `src/data.js`.
To add a project, drop a 16:9 image (1280×720 WebP works well) into `public/projects/` and add an entry to `projects`.
The CV served by the "Download CV" button is `public/Ashwini-Gathekar-CV.pdf`.

## Deploy to Vercel

1. Push this folder to a new GitHub repo (for example `portfolio`).
2. On vercel.com, choose **Add New → Project**, import the repo, keep the detected **Vite** preset, and deploy.
3. Optional: rename the project to `ashwini-gathekar` so the URL becomes `ashwini-gathekar.vercel.app`.
